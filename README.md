
# Project title
Nykaa Marketing Campaign Performance Dshboard

# Project Overview
The project analyzes Marketing campaign performance of nykaa , evaluating campaign effectiveness, customer engagement , ROI and revenue for optimize overall revenue using Excel and Power BI

# key business questions

1) Campaign performance

   - Which campaign type generates highest revenue ?
   - Which campaign type has highest ROI ?
   - Which campaign type drives most conversions ?

3) Customer segment analysis

 - Which customer segment converts best?
 - Which segment convert best with reasonable acquisition cost ?
 - Which segment has highest engagement score ?

4) Conversion funnel analysis
 
 - How the customer journey goes from impressions to conversions ?
 - Which stage is drops-off most of the customers ?
 
# Dataset
 
 Single table that contains :
_________________________________________________________________________________________________________________________________________________________________
|  Column Name   |   Description                                                                                                                           
|
| Campaign ID       Unique Identifier assigned to each marketing campaign.
|
| Campaign type     Types of marketing campaign such as Social Media, Influencer, SEO, Paid Ads or E-mail.
|
| Target Audience   intended Audience  segment for the campaign.
|
| Duration          Total number of days the campaign ran.
|
| Channels used     Marketing Channels used to execute Campaigns such as E-mail, Whatsapp, Youtube or multiple channels.
|
| Impressions       Total number of times campaign content was displayed to users.
|
| Clicks            Total number of clicks generated by the campaign.
|
|  Leads             Number of potential customers acquired through the campaign.
|
| Conversions       Number of users who completed the defined conversion action, such as making a purchase.
|
| Acquisition cost   Cost associated with acquiring customers through the campaign. Specify whether this is total campaign cost or cost per acquisition. 
|
| Revenue   	      Total revenue attributed to the campaign.
|
| ROI                Return On Investment, measuring the return generated relative to the investment made.
|
| Customer segment   Category used to group customers based on relevant characteristics or behavior
|
| Language           Language associated with the target audience or campaign.
|
| Engagement Score   Numerical measure of customer engagement with the campaign.
|
| Date               Date associated with the campaign or recorded observation.

# Key Insights

-INFLUENCER  (518.53K ) AND SOCIAL MEDIA (517.15K) CAMPAIGN GENERATED HIGHEST REVENUE ACROSS CAMPAIGNS WITH SLIGHTLY HIGHER COST IN THE INFLUENCER CAMPAIGN .
-COMPANY'S Ads VISIBILITY (IMPRESSIONS) IS HIGHER (3060M)  WHILE VISITORS IS ONLY 260M , THERE IS  A HUGE GAP BETWEEN REACH AND VISITORS THEN THE FINAL,CONVERSIONS IS ONLY ABOUT 57M.
-E-MAIL (22.8) , SEO (22.5) SHOWED HIGHER CONVERSION RATE BUT SOCIAL MEDIA AND E-MAIL CONVERTS BETTER IN THE TERMS OF CONVERSION COST.
-SOCIAL MEDIA (13.90) AND PAID Ads (13.80)  CAMPAIGNS SHOWED HIGHEST ENGAGEMENT SCORE WHERAS PAID Ads IS MORE COSTLY.
-COLLEGE STUDENTS, PREMIUM SHOPPERS AND TIER 2 CITY CUSTOMERS SHOWED HIGHER CONVERSION RATE WITH REASONABLE ACQUISITION COST.
